## 复核结论

- 登录：代码支持 `admin_users.email + password_hash` 登录；旧后台密码兼容入口仍保留并按超级管理员处理。由于测试账号未创建，真实多角色登录验收尚未完成。
- 左侧菜单：`AdminShell` 已按角色权限过滤。
- URL 直达限制：后台页面使用 `requireAdminPage(permission)` 服务端守卫。
- API 写入限制：申请、认证、支付、通知、主数据关键 API 使用 `requireAdminApiPermission` 返回 401 / 403。
- 只读限制：只读角色可进入列表和详情，但明显写操作区隐藏；API 写入仍会被拒绝。
- 危险确认：记录治理、联系方式修正、会员/认证审核、证书生成/状态、支付订单、付款凭证、通知单条发送已增加确认。
- 操作审计：已有 `audit_logs` 写入入口；部分写操作为 best-effort 审计，仍需后续统一审计覆盖率。
- SaaS 预留：角色、权限、用户、租户/组织/模块授权在 UI 与 SQL 草案中保留，但租户隔离尚未真实落库接入。

## 已可用与预留

已可用：
- 后台登录与会话。
- 后台首页工作台。
- 会员申请列表、详情、初审/复审、材料审核、会员有效期维护。
- 认证申请列表、详情、材料审核、证书记录、PDF 生成入口、公开核验资料预览。
- 支付订单列表、详情、凭证审核、状态维护。
- 通知记录列表与单条手动发送 / 模拟发送。
- 内容 CMS 静态结构化管理视图。
- 主数据配置读写入口。
- 审计日志读取入口。

仍是预留：
- 用户系统正式注册、邀请、禁用、绑定历史申请。
- admin_roles / admin_permissions / admin_user_roles 的数据库驱动权限计算。
- 租户、组织、模块授权的真实隔离。
- 内容 CMS 的真实数据库写入、发布工作流和媒体上传。
- 资料中心真实条目 CRUD、纠错、撤回与公开字段审批。
- 全量审计覆盖率和导出审计。
