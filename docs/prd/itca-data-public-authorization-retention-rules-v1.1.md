# ITCA 数据公开授权与数据保留规则 v1.1

## 1. 公开授权规则

- 个人库默认不公开。
- 个人公开字段必须逐项授权，授权范围包括姓名/公开名称、地区、身份类型、专长、认证状态、照片、简介等。
- 公开授权记录必须可追溯，保存授权时间、授权方式、授权范围、授权版本和撤回记录。
- 用户可撤回公开授权；撤回后前台隐藏，后台保留历史记录和审计。
- 机构公开需负责人或授权联系人确认。
- 传承、师承、法脉、谱系资料必须支持敏感等级：公开、会员可见、内部留档、限制访问。
- 公开前必须二次确认。
- 公开页面不得默认展示电话、邮箱、微信、WhatsApp、证件号、内部备注、私有附件路径。
- CMS 只能维护公开说明、FAQ 和标准文案，不得随意扩大公开 DTO 字段范围或覆盖授权状态。

## 2. 数据保留规则

| 数据类型 | 建议保留 | 说明 |
|---|---|---|
| 付款凭证 | 按财务与法务要求保留 | 不公开，访问需财务/审计权限 |
| 证书 PDF/vt 记录 | 证书生命周期内及归档期 | 历史证书继续可验证 |
| 审核记录 | 长期保留 | 认证公信力和争议处理依据 |
| 公开授权 | 长期保留 | 包括撤回记录 |
| 投诉申诉 | 长期或按法务要求 | 争议处理证据 |
| 审计日志 | 长期或按技术/法务策略 | 高风险操作必须留痕 |

## 3. 个人数据保护产品化原则

将同意、通知、选择、披露、安全、存储、数据完整性、访问与更正转为产品规则：申请前告知目的，公开前取得授权，用户可更正和撤回，敏感材料分级访问，数据导出审批审计，泄露事件进入应急流程。正式上线前需马来西亚本地法务复核。
