# ITCA 合规边界与标准文案库 v1.1

| 场景 | 标准文案 |
| --- | --- |
| 关于协会路径说明 | “规章制度”为“关于协会”下的制度内容分类；历史路径 `/rules` 可继续访问，后续如规范为 `/about/rules`，将保留兼容跳转说明。 |
| 频道首页说明 | 本频道首页用于说明频道定位、聚合重点内容并分流业务入口；申请表单、付款状态、证书核验、公开字段和权限逻辑不由 CMS 随意配置。 |
| 协会认证边界 | 本认证为 ITCA 协会认证建档，用于文化交流、会员服务和协会内部记录场景中的参考信息，不构成政府许可、行政执业资格或法定从业资质。 |
| 证书核验边界 | 公开核验只证明协会公开登记状态，不替代任何政府、监管机构或专业机构核查。 |
| 道教文化认证 / 道士认证名称风险 | “道士资格认证”等名称需秘书处和法务确认；对外优先使用“道教文化认证建档”等稳健表达。 |
| 道医、中医、养生、辟谷边界 | 相关内容仅作文化研究、养生知识交流和课程研修，不提供医疗诊断或治疗承诺，不替代医生建议。 |
| 易学、东方认知、AI 解读边界 | 相关内容仅作文化参考、认知辅助和自我成长参考，不构成医疗、法律、金融、心理诊断、婚姻或人生决策建议。 |
| 课程活动风险提示 | 参与者应根据自身情况谨慎参加，特殊人群需先咨询专业人士；线下活动需阅读风险告知。 |
| 未成年人参与规则 | 未成年人参加课程活动需监护人同意，未成年人个人信息默认不得公开。 |
| 个人信息公开授权说明 | 公开展示个人或机构信息前，将逐项列明公开字段并取得授权；授权可撤回。 |
| 数据中心公开说明 | 数据中心公开内容以已审核、已授权资料为准，敏感材料和联系方式默认不公开。 |
| 公开信息撤回说明 | 授权主体可申请撤回公开信息；撤回后前台隐藏，后台保留必要历史和审计记录。 |
| 退款 / 取消 / 活动延期说明 | 退款、取消或延期按具体活动、课程或订单规则处理，并保留付款与审核记录。 |
| 人工复核说明 | 如核验结果异常或未查询到记录，可提交人工复核，协会将按流程处理。 |
| 投诉申诉说明 | 投诉、申诉、纠错需提交必要证明材料，处理结果将记录留痕并通知申请人。 |
| 内容版权与来源说明 | 公开内容、图片、课程、讲义和第三方资料需具备来源或授权；侵权投诉将进入下架复核流程。 |
| 国际分会/机构互认边界 | 地区协会、国际分会、机构互认等信息以协会正式确认并发布的内容为准。 |
