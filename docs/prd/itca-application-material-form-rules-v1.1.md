# ITCA 申请材料与表单校验矩阵 v1.1

统一申请闭环：前台入口 -> 用户登录或登记联系方式 -> 阅读说明与合规边界 -> 填写表单 -> 上传材料 -> 提交申请 -> 生成申请编号 -> 如涉及费用，生成付款订单 -> 用户付款并上传凭证 -> 财务审核 -> 业务初审 -> 补件 / 驳回 / 复审 -> 审核通过 -> 生成业务档案 -> 如适用生成会员编号 / 证书编号 / 课程记录 / 数据条目 -> 通知用户 -> 前台可查询或后台可管理 -> 后续续期 / 复审 / 纠错 / 申诉 / 撤回 / 归档。

CMS 可维护申请说明、材料清单文案、FAQ、合规提示和附件说明；不得随意配置或绕过表单字段校验、必填规则、文件大小、文件类型、提交逻辑、付款订单状态、审核状态机、公开 DTO、证书 vt 访问规则或私有 Storage 路径。
