ITCA 官网 V2.0 原型设计图与交互说明

本入口用于查看本轮交付的关键页面原型。原型聚焦信息架构、业务闭环、CMS 维护关系、用户中心和 SaaS 化后台，不作为最终生产视觉代码。

交付范围

前台频道、业务申请、用户中心、后台 CMS、RBAC 与委员会业务原型。

Pages

关键页面原型

每个页面均使用统一 Header，桌面端横向导航，移动端单行横滑。公共页面保持正式协会门户质感，后台页面体现 SaaS 管理结构。

01 / Portal

首页

协会总门户、核心服务、V1.3 闭环、公告与查询入口。

02 / About

关于协会

协会介绍与规章制度合并，包含组织架构与联系入口。

03 / Membership

会员服务

个人会员、机构会员、申请编号、支付凭证、公众核验。

04 / Certification

认证服务

道士认证申请、材料审核、补件、支付审核、发证和 PDF 下载。

05 / Committee

委员会业务

需求方自行筹办、申请、审核、自行运营、发展中心监督。

06 / Account

用户中心

我的申请、我的会员、我的证书、补件、付款凭证、PDF 下载。

07 / Admin

后台管理首页

待办、会员、认证、委员会、CMS、主数据、用户权限入口。

08 / CMS

CMS 栏目首页维护

每个顶部频道按模板维护栏目首页，而不是卡片填充。

09 / RBAC

RBAC 权限管理

用户、角色、菜单权限、操作权限、审核权限和审计。

开发边界

本轮只做 PRD 与原型补充，不新增 SQL，不执行 SQL，不修改数据库，不发布 Production，不 push 远端，不删除现有业务代码。若后续发现现有路由、字段、接口与 PRD 不一致，应先在文档中列出差异，再进入独立开发任务。
