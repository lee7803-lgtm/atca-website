RBAC

权限管理

后台权限需要从单一管理员工具升级为用户、组织、角色、菜单、操作、审核节点、数据范围和敏感字段权限共同控制的 SaaS 化权限体系。

Roles

角色清单

以下角色为 V2.0 最小可用角色集合。后续可按组织和业务线扩展。

super_admin

超级管理员

全部权限、系统配置、角色权限和关键操作审批。

association_admin

协会管理员

协会日常运营、跨模块协调、后台总览和内容确认。

content_admin

内容管理员

频道首页、公告、内容页、推荐位、媒体素材和提交发布。

member_reviewer

会员审核员

个人会员、机构会员申请审核、补件和会籍状态维护。

cert_reviewer

认证审核员

认证材料审核、补件、复审和证书信息准备。

finance_reviewer

财务审核员

付款凭证查看、付款审核、paid 状态确认和财务导出。

committee_admin

委员会管理员

委员会申请审核、监督记录、年度报告和任务缴纳管理。

readonly_observer

只读观察员

查看后台总览、列表和审计日志，不执行写操作。

Permission Matrix

菜单、操作与审核权限

RBAC 不只控制菜单显示，还必须控制按钮、审核动作、数据范围和敏感字段。

模块 菜单权限 操作权限 审核权限 敏感字段
会员管理 会员审核员 / 超级管理员 查看、新增审核意见、要求补件、生成会员编号 初审、复审 联系方式、证件信息按角色脱敏
认证管理 认证审核员 / 超级管理员 材料审核、补件、复审、证书信息准备 认证初审、认证复审、发证确认 申请材料、证书照片、内部备注受控
支付管理 财务审核员 / 超级管理员 查看凭证、确认 paid、退回凭证、导出 财务审核 付款凭证、金额、银行流水受控
委员会管理 委员会管理员 / 发展中心 / 超级管理员 审核申请、记录监督、年度报告、任务缴纳状态 初审、复审、监督确认 负责人联系方式、内部监督意见受控
CMS 内容管理员 / 协会管理员 草稿、编辑、提交审核、发布、下架、回滚 内容审核、合规审核 未发布草稿和高风险内容受控
用户权限 超级管理员 邀请、禁用、角色分配、数据范围配置 权限变更二次确认 账号、登录记录、权限变更记录受控

Role Editor

角色配置面板

角色配置变更必须记录变更原因、操作者、时间、前后权限，并在高风险角色上触发二次确认。

编辑角色：财务审核员

权限校验要求

前端菜单隐藏只是体验优化，后端 API 必须校验用户、角色、菜单、操作、审核节点、数据范围和敏感字段权限。任何越权访问都应拒绝并写入安全日志。

Audit

权限审计

权限系统的每次关键变更都要可追踪，避免后台长期依赖单一密码或不可审计的超级权限。
