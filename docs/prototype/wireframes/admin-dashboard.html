后台管理首页

后台不是单一管理员工具，而是可扩展的 SaaS 管理后台。模块需支持组织、角色、权限、用户、内容、主数据、审核、日志和多业务线管理。

Queues

今日待办

待办点击后进入对应模块的筛选列表。每个模块需要按角色控制可见范围和可执行动作。

会员审核员

个人 / 机构会员待审核

检查申请资料、引荐人、机构信息和材料附件，必要时发起补件。

认证审核员

认证材料待审核

处理道士认证申请、材料审查、复审、证书信息准备和补件意见。

财务审核员

付款凭证待确认

确认银行电汇金额、账户和凭证真实性，paid 状态只能由财务确认。

委员会管理员

委员会申请与年度报告

处理筹备申请、运营决议、年度报告、任务缴纳和发展中心监督记录。

Modules

SaaS 后台模块入口

模块可配置，权限可控制，关键操作必须写入审计日志。

申请

申请审核

会员、机构、认证申请列表、详情、补件和状态流转。

会员

会员档案

会员编号、状态、有效期、公开核验字段和导出。

认证

证书管理

证书编号、PDF、公开核验、暂停、撤销和恢复。

委员会

委员会管理

申请、审核、运营记录、年度报告、任务缴纳和监督。

CMS

栏目首页维护

10 个顶部频道均支持频道首页模板维护和审核发布。

主数据

基础资料

引荐人、宫观机构、认证等级、费用项目、地区和模板。

权限

用户 / 角色 / 权限

菜单权限、操作权限、审核权限、数据范围和敏感字段权限。

审计

日志与导出

登录、审核、付款、发证、内容发布、权限变更和导出记录。

Risk

后台风险提醒

Production、SQL、付款确认、证书签发、公开字段、权限变更均属于高风险操作。

SQL 与数据库

默认不执行 SQL，不直接修改生产数据库。数据库变更必须先提交 SQL 草案和审批说明。

财务与发证

paid、发证、撤销、暂停、PDF 生成和公开字段修改必须保留审计日志。

权限与审计

菜单不可见不等于接口无权限，后端 API 必须校验角色、操作和数据范围。
