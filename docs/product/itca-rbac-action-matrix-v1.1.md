## 职责冲突规则

1. 初审和终审原则上不得同一人完成；例外需 Super Admin 审批并写入审计。
2. 财务审核和业务审核应分离；同一人不得同时确认付款并终审同一申请。
3. 证书撤销需要 Certificate Manager 或 Super Admin 权限、撤销原因、二次确认和审计。
4. 数据导出需要审批和审计，导出用途、范围、导出人、审批人、时间必须记录。
5. 批量操作必须记录，批量撤销、公开、导出需二次确认。
6. 管理员离职、停用或角色变更后必须立即回收权限并记录审计。
7. 删除原则上改为归档，不做物理删除；生产数据修改必须填写原因。
