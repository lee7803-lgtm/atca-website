## 状态标记说明

| 标记 | 含义 |
|---|---|
| 已覆盖 | v1.1 蓝图已明确规则，可进入后续 UI/技术细化 |
| 部分覆盖 | 有方向但仍需秘书处、法务、财务、技术或运营确认 |
| 缺失 | 原 v1.0 未覆盖，v1.1 已补为蓝图规则 |
| 高风险 | 涉及认证公信力、个人数据、付款、证书、权限、医疗/易学边界或生产兼容 |
| 待确认 | 不应由 PRD 单方决定，需指定责任方确认 |
