## 1. 文档信息

| 项目 | 内容 |
| --- | --- |
| 文档名称 | ITCA 官网顶部导航栏目与频道 CMS 管理方案评审稿 v1.1 |
| 日期 | 2026-06-11 |

## 2. 背景与问题

当前 V2.0 官网顶部导航已经形成：首页、介绍、规章制度、道教信仰、教理教义、文化交流、发展中心、会员体系、认证体系、查询核验、发展合作、资料中心。

其中“介绍”实际承担的是“关于协会”的职能。为符合公众认知和协会官网表达，建议顶部导航显示名由“介绍”调整为“关于协会”。其他顶部导航栏目暂不调整命名。

当前 PRD 已覆盖业务闭环、认证闭环、会员闭环、支付、通知、权限、数据中心和合规边界，但对“顶部导航栏目页如何由后台管理”“频道页面包含哪些结构”“后台如何添加内容和版式”描述不足。本评审稿用于补齐该部分。

## 3. 顶部导航建议

### 3.2 导航后台管理要求

顶部导航本身也应进入后台管理，但必须设置保护规则，避免误删核心入口。

| 配置项 | 是否后台可管理 | 规则 |
| --- | --- | --- |
| 导航显示名称 | 是 | 可把“介绍”改为“关于协会”；核心栏目改名需超级管理员或秘书处确认 |
| 路径 URL | 受限管理 | 核心路径不建议普通内容管理员修改；如需迁移，必须保留旧路径兼容 |
| 排序 | 是 | 支持拖拽排序或数字排序 |
| 是否显示 | 是 | 首页、查询核验、会员体系、认证体系建议设为核心入口，隐藏需二次确认 |
| 二级菜单 | 是 | 发展中心必须支持二级栏目；其他频道可按需扩展二级菜单 |
| 多语言标题 | 预留 | 中文优先，英文、马来文等后续扩展 |
| SEO 标题和摘要 | 是 | 每个频道独立配置 |
| 发布状态 | 是 | 草稿、待审核、已发布、已下架、已归档 |

## 4. CMS 管理范围

### 4.1 频道页面类型

| 页面类型 | 是否纳入 CMS | 说明 |
| --- | --- | --- |
| 顶部导航频道页 | 是 | 关于协会、规章制度、信仰、教义、交流、发展中心、会员、认证、合作、资料中心 |
| 顶部导航子频道页 | 是 | 六大发展中心详情页、制度分类页、资料库分类页等 |
| 文章详情页 | 是 | 公告、制度文档、文化文章、交流报道、课程活动报道 |
| 聚合查询页 | 半管理 | 查询核验页的说明文案、入口卡片、边界说明可管理；查询表单逻辑不可由 CMS 改动 |
| 申请表单页 | 半管理 | 说明文案、材料清单、流程说明可管理；字段校验和提交逻辑不可由 CMS 改动 |
| 首页 | 半管理 | 首页核心区块、入口、公告、推荐内容可管理；首页路由和核心业务入口不可误删 |
| 后台管理页 | 否 | 后台页面不是前台 CMS 内容页 |

### 4.2 后台模块建议

建议在后台新增或强化“内容管理 / 栏目管理”模块，并与“发展中心管理”“资料中心管理”“公告管理”协同。

| 后台模块 | 管理对象 | 说明 |
| --- | --- | --- |
| 栏目管理 | 顶部导航、二级导航、频道状态 | 管理导航名、路径、排序、是否显示、图标、SEO |
| 页面管理 | 频道页、落地页、聚合页 | 管理页面标题、Hero、区块、版式、发布状态 |
| 内容库 | 文章、公告、制度、文化资料 | 管理内容条目、分类、标签、正文、附件 |
| 版式库 | 页面区块模板 | 提供 Hero、卡片组、图文、时间线、FAQ、下载列表等区块 |
| 媒体库 | 图片、PDF、附件、封面图 | 管理上传、替换、alt 文案、来源和授权 |
| 审核发布 | 草稿、预览、审核、发布、下架 | 对高风险内容进行秘书处/法务确认 |
| 版本记录 | 页面和内容版本 | 支持查看历史版本、回滚、变更说明 |
| 内容审计 | 操作记录 | 记录创建、修改、审核、发布、下架、删除申请 |

## 5. 频道页面结构建议

### 5.1 通用频道页结构

每个频道页面建议统一支持以下结构：

| 区块 | 是否必需 | 后台可配置内容 |
| --- | --- | --- |
| SEO 信息 | 必需 | SEO 标题、SEO 摘要、关键词、规范路径 |
| Hero 首屏 | 必需 | 栏目标题、副标题、简介、背景图、主按钮、次按钮 |
| 栏目导语 | 必需 | 频道定位、适用人群、内容边界 |
| 内容区块 | 必需 | 可由版式库添加多个区块 |
| 推荐入口 | 可选 | 申请、查询、合作、课程、公告、资料库入口 |
| 边界说明 | 高风险栏目必需 | 认证、道医、易学、数据公开、未成年人等边界文案 |
| 关联内容 | 可选 | 相关文章、制度、公告、活动、发展中心、资料库条目 |
| 发布信息 | 必需 | 发布状态、发布时间、更新人、审核人、版本号 |

### 5.10 查询核验

当前路径可继续指向 `/certificate-query`。后续建议升级为查询核验聚合页，统一承接：

| 查询类型 | 当前入口 | 页面要求 |
| --- | --- | --- |
| 证书公开核验 | `/certificate-query` | 证书编号 + 持证人姓名，成功后短期 vt 查看详情 |

- 边界提示。
- 常见问题。

查询表单逻辑、字段校验、公开 DTO、安全策略不能由 CMS 直接修改。

## 6. 版式库建议

后台页面编辑器不建议完全自由拖拽，以免前台视觉和合规失控。建议采用“受控版式库”。

| 版式名称 | 用途 | 可配置字段 |
| --- | --- | --- |
| Hero 首屏 | 频道首页顶部 | 标题、副标题、简介、背景图、按钮、视觉标识 |
| 三/六卡片组 | 频道入口、服务对象、规则分类 | 卡片标题、摘要、图标、链接、标签 |
| 富文本区块 | 制度正文、栏目说明、介绍文字 | 标题、正文、引用、链接 |
| 图文区块 | 文化介绍、项目展示 | 图片、标题、正文、按钮、左右布局 |
| 时间线 | 发展历程、制度修订、项目进度 | 时间、标题、说明、图片 |
| 文件下载列表 | 制度、PDF、附件 | 文件名、版本、发布日期、生效日期、下载权限 |
| FAQ | 常见问题 | 问题、答案、分类、排序 |
| 公告列表 | 公告聚合 | 分类、标签、数量、排序 |
| 文章列表 | 文化文章、交流动态 | 分类、标签、数量、展示方式 |
| 活动/课程列表 | 课程活动聚合 | 活动状态、报名状态、日期、地点 |
| 数据库入口组 | 资料中心八类库 | 库名称、说明、图标、链接、公开数量 |
| 边界说明框 | 高风险内容提示 | 标题、说明、适用栏目、确认人 |
| CTA 操作区 | 申请、查询、合作入口 | 按钮、说明、链接、权限提示 |

## 7. 内容发布流程

建议所有频道内容使用统一流程：

```text
草稿 -> 内容编辑 -> 预览 -> 提交审核 -> 秘书处/法务/业务负责人确认 -> 定时发布或立即发布 -> 变更记录 -> 下架/归档
```

| 状态 | 含义 | 权限 |
| --- | --- | --- |
| 草稿 | 内容管理员编辑中 | 创建人、内容管理员 |
| 待审核 | 已提交审核 | 审核员、秘书处 |
| 待法务/秘书处确认 | 涉及认证、道医、易学、隐私、制度、费用等高风险内容 | 法务/秘书处/超级管理员 |
| 已发布 | 前台可见 | 内容管理员可提交修改，发布需审核 |
| 定时发布 | 到时间自动发布 | 内容管理员设置，审核后生效 |
| 已下架 | 前台不可见 | 需记录原因 |
| 已归档 | 历史留存 | 只读，不建议删除 |

## 8. 权限建议

| 角色 | 可操作范围 |
| --- | --- |
| 超级管理员 | 全部栏目、导航、页面、版式、发布、下架、回滚、权限分配 |
| 秘书处管理员 | 审核关于协会、规章制度、公告、合作、发展中心重要内容 |
| 内容管理员 | 创建和编辑频道页面、文章、公告、FAQ、媒体，不可直接发布高风险内容 |
| 发展中心管理员 | 编辑对应发展中心内容、项目、课程活动和成果 |
| 资料中心管理员 | 编辑资料库条目、公开字段、授权状态、纠错撤回 |
| 法务/合规审核员 | 审核制度、认证边界、隐私、道医、易学、费用、退款等内容 |
| 只读审计员 | 查看版本记录、发布记录、操作日志 |

## 10. 验收标准

- 顶部导航“介绍”显示名可调整为“关于协会”。
- 核心栏目页面均可在后台配置标题、简介、Hero、区块、SEO、发布状态和边界说明。
- 内容管理员可通过受控版式库新增页面区块，而不是直接写代码。
- 高风险栏目内容发布前必须经过审核确认。
- 页面修改有版本记录，可查看修改人、修改时间、修改内容和审核意见。
- 下架、归档、删除申请必须记录原因。
- 查询核验、申请表单、支付、证书 vt、公开 DTO 等业务逻辑不能被 CMS 配置绕开。
- 首页、会员申请、认证申请、查询核验等核心入口隐藏或改路径需二次确认。
- 前台页面在移动端和桌面端均能正常展示后台配置内容。

## 12. 补充建议

### 12.1 栏目、页面、内容的关系

建议把 CMS 分为三层，不要把所有内容混在一个“文章管理”里。

| 层级 | 定义 | 示例 | 后台管理重点 |
| --- | --- | --- | --- |
| 栏目 Channel | 导航和频道容器 | 关于协会、规章制度、发展中心、资料中心 | 名称、路径、排序、是否显示、SEO、二级栏目 |
| 页面 Page | 一个可访问页面 | `/rules`、`/development/education` | Hero、区块、版式、发布状态、版本 |
| 内容 Item | 可被页面引用的内容条目 | 公告、制度、文章、活动报道、FAQ、下载文件 | 分类、正文、附件、标签、审核、有效期 |

页面可以引用多个内容条目，内容条目也可以被多个页面引用。例如“认证边界说明”可以同时出现在认证体系、规章制度和查询核验页面。

### 12.2 核心路径保护

以下路径属于核心业务入口，不建议普通内容管理员修改或隐藏：

| 路径 | 保护原因 | 修改要求 |
| --- | --- | --- |
| `/` | 官网首页 | 超级管理员二次确认 |
| `/membership` | 会员体系入口 | 秘书处或超级管理员确认 |
| `/certification` | 认证体系入口 | 秘书处或超级管理员确认 |
| `/certificate-query` | 证书公开核验 | 不允许通过 CMS 关闭查询能力 |
| `/member-query` | 会员公开核验 | 不允许通过 CMS 关闭查询能力 |
| `/application/query` | 申请进度查询 | 不允许通过 CMS 关闭查询能力 |
| `/admin/*` | 后台系统 | 不纳入前台 CMS |

CMS 可以管理这些页面的说明文案、入口卡片和边界提示，但不能改变业务提交、查询、核验和鉴权逻辑。

### 12.3 页面编辑器建议

页面编辑器建议采用“左侧区块树 + 中间预览 + 右侧属性面板”的结构。

| 区域 | 功能 |
| --- | --- |
| 左侧区块树 | 显示 Hero、导语、卡片组、文章列表、FAQ、边界说明等区块，可排序、隐藏、复制 |
| 中间预览 | 展示桌面端和移动端预览，支持切换语言和发布状态 |
| 右侧属性面板 | 编辑当前区块的标题、正文、图片、按钮、链接、标签、显示规则 |
| 顶部操作栏 | 保存草稿、预览、提交审核、发布、下架、查看版本、返回列表 |

页面编辑器不建议开放任意 HTML 或自由拖拽布局。所有页面应使用受控区块，避免破坏前台视觉一致性和合规边界。

### 12.4 首页 CMS 边界

首页建议纳入“区块配置型 CMS”，但不开放完全自由改版。

| 首页区块 | 是否可管理 | 规则 |
| --- | --- | --- |
| 首屏 Hero | 是 | 可改标题、简介、按钮、背景图；核心业务入口不可删 |
| 快捷入口 | 是 | 会员、认证、查询、合作、资料中心等入口可排序，不可全部隐藏 |
| 公告摘要 | 是 | 可配置展示数量、分类和排序 |
| 发展中心推荐 | 是 | 六大发展中心可排序，可替换摘要 |
| 认证/会员说明 | 是 | 文案需走审核 |
| 页脚联系信息 | 是 | 修改联系方式需秘书处确认 |

### 12.5 高风险内容审核规则

以下内容必须进入加强审核：

| 内容类型 | 审核要求 |
| --- | --- |
| 认证、资格、证书、会员权益 | 秘书处确认，必要时法务确认 |
| 道医、中医、养生、辟谷、功法修炼 | 必须带非医疗边界说明 |
| 易学、AI 解读、东方认知 | 必须带文化参考和非专业建议说明 |
| 费用、付款、退款、收据 | 财务和秘书处确认 |
| 隐私、数据公开、个人库、未成年人 | 数据保护/法务确认 |
| 国际分会、机构互认、合作背书 | 秘书处确认，不得暗示未确认授权 |
| 制度文件和公告 | 需版本号、生效日期、审核人 |

### 12.6 SEO 与多语言预留

| 能力 | 建议 |
| --- | --- |
| SEO 标题 | 每个栏目页、文章页、制度页独立配置 |
| SEO 摘要 | 控制在适合搜索展示的长度，避免夸大认证资质 |
| 规范路径 canonical | `/intro` 与 `/about` 兼容时尤其需要 |
| Open Graph 图片 | 每个频道可配置分享图 |
| 多语言字段 | 先预留 `zh`、`en`，后续扩展 `ms` 等语言 |
| 翻译状态 | 未翻译、待翻译、待校对、已发布 |

### 12.7 媒体库与附件规则

| 类型 | 规则 |
| --- | --- |
| 图片 | 必须有 alt 文案、来源说明，可选授权说明 |
| PDF 制度文件 | 必须记录版本、生效日期、上传人、审核人 |
| 活动图片 | 涉及个人肖像时需授权或采用公开活动授权规则 |
| 证件、申请材料 | 不进入公开媒体库 |
| Storage path | 不对前台和普通后台用户展示原始路径 |
| 替换文件 | 保留历史版本，不直接覆盖到无法追溯 |

### 12.8 搜索与筛选

前台建议支持：

- 站内关键词搜索。
- 按栏目筛选：关于协会、制度、信仰、教义、交流、发展中心、资料中心。
- 按内容类型筛选：公告、制度、文章、活动、FAQ、资料条目。
- 按发布时间排序。
- 高风险内容不建议默认通过搜索展示未审核草稿。

后台建议支持：

- 按栏目、状态、创建人、审核人、发布时间、更新时间筛选。
- 按内容类型、标签、风险等级筛选。
- 按“待我审核”“我创建的草稿”“近期下架”“即将生效制度”筛选。

### 12.9 与现有 V2.0 页面兼容

当前 V2.0 多个频道页已经通过 `V2InfoPage` 和 `lib/v2/content.ts` 的结构化内容渲染。CMS 化时可把现有结构作为第一版内容模型参考：

| 现有结构 | CMS 对应 |
| --- | --- |
| `V2PageData.title` | 页面标题 |
| `V2PageData.intro` | Hero 简介 |
| `V2PageData.actions` | Hero 按钮 |
| `V2PageData.imageSrc` | 主视觉图片 |
| `V2PageData.sections` | 页面区块列表 |
| `V2Section.cards` | 卡片组区块 |
| `boundaryNotices` | 边界说明区块 |

迁移时不建议一次性重写前台页面。可先在后台建立 CMS 数据模型，再把现有静态内容导入为首批内容。
