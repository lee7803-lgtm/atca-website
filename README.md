# ITCA Website

ITCA · International Taoisme And Cultural Association（国际道教与文化协会）官网，基于 Next.js、TypeScript 和 TailwindCSS 构建。

## 本地开发

```bash
npm install
npm run dev
```

默认预览地址为 http://localhost:3000。

## Logo 替换

如需替换官网 Logo，只需替换 `public/images/brand/itca-logo-mark.png`，并保持文件名不变。

## 编号规则

- 个人会员申请编号：`ITCA-M-2026-******`
- 机构会员申请编号：`ITCA-O-2026-******`
- 道士资格认证申请编号：`ITCA-TAO-2026-******`
- 道士资格认证证书编号：`ITCA-TAO-2026-******`
